### ColorReverse
自主制作 / 制作期間：約2週間
個人制作（プログラム・デザイン・企画）

ゲーム概要
プレイヤーは三角形のキャラクターを操作し、乗っている色と同じ色のギミックに当たるゲームです。

自キャラが 白に乗っている間は白のギミック にしか触れてはいけない

他の色（例：赤・青・緑など）に触れると 即アウト！

色の組み合わせとギミック配置を見極めて、先へと進みましょう！

工夫した点
ScriptableObject を使ってギミックデータを管理
　→ プログラマー以外の人でもエディタから簡単にギミックの色や挙動を設定可能に
　
反省点・今後の改善
「乗っている色のギミックにだけ触れられる」というルールがやや直感的ではなく、
　初見プレイヤーにとって混乱しやすい点が課題
　→ チュートリアルUIやエフェクトなど、視覚的フィードバックの強化が必要

🛠 使用技術・環境
Unity（URP）

ScriptableObject によるギミック管理システム
